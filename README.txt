# TrackCard Website

Open `index.html` to preview the site.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload EVERYTHING in this folder, including the `assets` folder.
3. In GitHub: Settings → Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Choose `main` and `/ (root)`, then Save.
6. GitHub will give you the public website URL.

## Before the Shark Tank presentation
- Replace the YouTube demo iframe in `index.html` with your own video URL.
- The interactive "Find My TrackCard" button is a website simulation, not a live hardware connection.
